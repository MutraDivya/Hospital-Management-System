# 🏥 Hospital Management System

## 📌 Overview

The Hospital Management System is a console-based Python application developed using Object-Oriented Programming (OOP) and SQLite. It helps manage hospital operations by maintaining patient records, doctor information, and appointment scheduling through a modular architecture.

---

## ✨ Features

### Patient Management
- Add Patient
- View Patients
- Update Patient
- Delete Patient
- Search Patient

### Doctor Management
- Add Doctor
- View Doctors
- Update Doctor
- Delete Doctor

### Appointment Management
- Book Appointment
- View Appointments
- Cancel Appointment

### Additional Features
- SQLite Database
- Input Validation
- Exception Handling
- Foreign Key Relationships
- Modular Project Structure

---
